使用帮助

本软件用于儿童英语词汇学习，支持单元化复习、听音训练、拼写训练、错词复习、学习统计和 Excel 词库导入。

基本使用流程

  1. 在“导入”页复制粘贴 Excel，或导入 CSV。
  2. 在“考试”页选择年级、学期、单元和模式。
  3. 听音题点击“播放单词”，或按空格播放发音。
  4. 听音拼写中，输入完成后按 Enter 提交；提交后按 Space 进入下一题。
  5. 在“错词”和“统计”页面查看学习情况。
  6. 在“数据”页导出备份，迁移或分享词库。

考试模式

  1. 听音认词：听声音，选择英文 + 中文。
  2. 看中文选英文：看中文，选择英文。
  3. 听音选拼写：听声音，选择正确拼写。
  4. 听音拼写：听声音，手动输入拼写。
