儿童英语单词学习软件 v5.1 Android WebView 项目

构建步骤：
1. 安装 Android Studio。
2. 打开 Android Studio，选择 Open，打开本文件夹。
3. 等待 Gradle Sync 完成。
4. 菜单 Build → Build Bundle(s) / APK(s) → Build APK(s)。
5. 点击 locate 找到 app-debug.apk，发送到联想小新平板安装。

说明：
- 离线运行，内置 v5.1 HTML。
- 授权码仍使用原 v4.3 同一套。
- 发音优先使用 Android 原生 TextToSpeech，不再依赖浏览器 speechSynthesis。
- 学习数据保存在 App WebView 本地存储中，卸载 App 会删除数据。
